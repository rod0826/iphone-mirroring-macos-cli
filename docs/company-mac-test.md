# 회사 Mac 시험 안내

비공식 실험용 PoC이며 Apple 또는 회사 IT 부서가 승인한 제품을 뜻하지 않습니다.
회사 장비의 설치·접근성 권한 정책을 먼저 확인하세요.

## 배포 방식

- GitHub: 소스, 사용법, 검증 범위, 라이선스만 공개합니다.
- 회사 Mac용 설치 ZIP: 별도 전달 경로로 제공합니다. GitHub Releases에는 올리지 않습니다.
- GitHub의 Download ZIP은 소스 묶음이며 설치 패키지가 아닙니다.
- 현재 저장소는 개발자용 빌드 절차를 제공합니다. Python 런타임을 포함한 독립 설치기나
  자동 설치·권한 부여 프로그램은 이 PoC에 구현되어 있지 않습니다.

별도 ZIP을 전달할 때는 버전, 대응 소스 커밋, 대상 아키텍처·macOS, 포함 파일,
설치·제거 절차, SHA-256 체크섬을 함께 전달합니다. 받은 ZIP은 그 안내를 따르세요.
다른 Mac에서 빌드한 앱은 권한을 새로 등록해야 하며 이 Mac의 허용 기록이 이전되지 않습니다.

## 실행 조건

Apple iPhone 미러링 앱, 사용자가 완료한 최초 연결·인증, 로그인된 Mac 데스크톱이
필요합니다. 앱 번들 IPhoneMirroringCLI.app에 손쉬운 사용 권한을 부여합니다.
회사 정책이 권한 부여를 막으면 IT 담당자에게 확인하세요.

보조 앱은 개발용 ad-hoc 서명이며 Developer ID 서명·공증을 받지 않았습니다.
Gatekeeper나 회사 보안 정책이 실행을 제한할 수 있습니다. 보안 기능을 일괄 해제하는
설치 절차는 제공하지 않습니다. 앱 재빌드 후에는 해당 앱의 권한 재등록이 필요할 수 있습니다.

## 시험 순서

1. doctor로 버전과 accessibility_trusted를 확인합니다.
2. inspect로 주 창과 도구 모음을 확인합니다. 개인 화면 텍스트를 공개 이슈에 올리지 마세요.
3. dry-run home 후 home을 실행하고 화면을 직접 확인합니다.
4. 빈 검색창 등 되돌리기 쉬운 화면에서 한글 입력·backspace를 시험합니다.

posted/requested는 입력 전달 상태이며 성공 판정이 아닙니다. verified는 false,
connection은 unknown입니다. 앱 내부 요소 조회와 자동 결과 판정은 지원하지 않습니다.
메시지 전송·결제·설정 변경을 유발할 수 있는 화면에서는 좌표와 키 입력에 주의하세요.
