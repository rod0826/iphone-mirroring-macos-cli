# 0.1.3 검증 — 2026-11-20

0.1.3(빌드 4)은 개인 테스트용 최종 버전입니다. GPT Image로 생성한 프로젝트 아이콘을 macOS 보조 앱과 저장소에 적용했습니다. CLI 진단과 iPhone 입력 동작은 0.1.2의 구현을 사용합니다.

## 검증 범위

- Python 단위·호스트·패키징 테스트 43개와 Swift 창·홈 화면 정책 테스트 15개가 통과했습니다. wheel을 설치해 CLI·보조 앱 버전, 아이콘 리소스, 보조 앱 서명을 확인했습니다. 호스트 진단 당시 Apple 앱은 실행 중이 아니었고, 새 보조 앱의 손쉬운 사용 권한은 등록되지 않은 상태였습니다.
- 새 아이콘이 들어 있는 보조 앱 코드 서명 검증과 Apple Silicon 설치 ZIP의 외부·내부 SHA-256 검증.
- ZIP을 압축 해제해 설치 경로에 복사한 뒤 실행 파일, 앱 아이콘, CLI·보조 앱 버전 확인.

0.1.3에서 연결된 iPhone 실기기 입력, 회사 Mac의 Gatekeeper, 빌드 간 손쉬운 사용 권한 유지는 시험하지 않았습니다. 과거 버전의 관찰 결과는 [0.1.2 검증](verification-0.1.2.md)과 저장소의 VERIFICATION.md에 기록합니다.
