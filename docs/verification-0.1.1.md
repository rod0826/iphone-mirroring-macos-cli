# 0.1.1 검증 — 2026-10-27

## 수정과 회귀 검증

- 이슈 #1: Apple 앱이 호버 전에 탐색 AX 버튼을 노출하지 않는 회사 Mac 관찰을 근거로, 버튼 부재 시 검증된 주 창의 상단으로 마우스를 이동해 재조회합니다.
- 기존 조회 동작은 가짜 UI의 호버 후 버튼 노출 테스트에서 실패했습니다. 수정 후 숨은 버튼, 이미 노출된 버튼, 계속 없는 버튼, 재시도 중 창·포커스 변경, 최초 검증 실패의 5사례가 통과했습니다.
- 앱·창 식별·프레임·포커스·요청 만료 검사는 유지하며, 마우스 버튼이 눌린 상태에서는 호버를 중단합니다. 클릭·단축키를 대신 보내지 않습니다.
- 이슈 #2: 단일 ZIP에 파일별 SHA256SUMS와 검증.command를 포함합니다. 외부 .zip.sha256는 ZIP 자체 확인용 선택 파일입니다.
- 압축 해제 뒤 별도 경로에서 검증 성공, 파일 변조 뒤 검증 실패와 설치 전 중단, 검증 전후 격리 속성 유지의 배포 테스트 2개가 통과했습니다.
- 격리 속성 제거는 문서의 사용자 선택 절차일 뿐 설치기·검증기에서 실행하지 않습니다.

## 실제 기기 재검증 범위

개발 Mac에서 Apple 앱은 iPhone 사용으로 인한 연결 시간 초과 상태였고, 새 보조 앱 접근성 허용도 필요했습니다. 이번 수정의 실제 iPhone 호버·탐색과 회사 Mac의 Gatekeeper 동작은 아직 재검증하지 않았습니다. 이전 0.1.0의 입력 결과는 VERIFICATION.md에 별도로 보존합니다.

회사 Mac에서 0.1.1의 새 보조 앱을 등록한 뒤 포인터를 미러링 창 밖에 두고 home → search → app-switcher → home을 확인해야 합니다. inspect와 dry-run은 포인터를 움직이지 않습니다.
